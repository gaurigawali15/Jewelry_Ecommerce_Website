# Jewelry_Ecommerce_Website
A full-stack e-commerce web application developed using PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap. The platform allows customers to browse products, manage their shopping cart, place orders, and enables administrators to manage products, categories, and orders through an admin dashboard.
---

## 📌 Features

### 👤 User Module
- User Registration & Login
- Browse Jewelry Products
- Search Products
- View Product Details
- Add to Cart
- Update Cart Quantity
- Place Orders
- View Order Details
- Responsive User Interface

### 🛠️ Admin Module
- Secure Admin Login
- Dashboard Overview
- Add/Edit/Delete Products
- Manage Categories
- Manage Customers
- Manage Orders
- Update Order Status
- Product Image Management

## 💻 Installation

### Step 1
Install **XAMPP** on your computer.

### Step 2
Copy the project folder into:

```
C:\xampp\htdocs\
```

### Step 3
Start:

- Apache
- MySQL

from the XAMPP Control Panel.

### Step 4
Open **phpMyAdmin**.

Create a database named:

```
jewelry_db
```

### Step 5

Import the SQL file:

```
jewelry_db.sql
```

### Step 6

Run the project in your browser:

```
http://localhost/Jewelry-Ecommerce-Platform/
```
